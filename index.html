最近拍摄

iPhone：点「分享 / 保存到照片」，在系统分享菜单中选择「存储图像」。如果没有该选项，可以长按上方照片保存。

TrueView 使用帮助

真实模式（默认）：摄像头画面不作水平翻转，画面里的文字方向正常。
镜像模式：像照镜子一样左右翻转，照片保存时也保持镜像。

安装到 iPhone 主屏幕

  1. 使用 Safari 打开已部署的 HTTPS 网页。
  2. 点击 Safari 的「分享」按钮。
  3. 选择「添加到主屏幕」。
  4. 以后从主屏幕打开即可全屏使用。

注意：iPhone 要求在 HTTPS 网站上授权使用摄像头。直接从「文件」App 打开 HTML 可能无法获得摄像头权限。本程序不上传照片，但网页托管平台仍会提供页面文件。
